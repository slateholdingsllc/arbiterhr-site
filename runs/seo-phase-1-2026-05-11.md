## Bug fixes applied during build

- **Oregon P7 jurisdictional callout**: original implementation branched on the `law_status` column (vocab: "Law Active", "No Law", free text). The cover risk_levels vocab ("Statewide", "City-Only", "No Law") lives in the `status` column. Switched the branch to `status` so Oregon correctly renders "Oregon has a statewide predictive scheduling law…" instead of the no-law fallback.
- **P9 topic hub lure**: the No-General-Garnishment filter was triggering on `stateAb` being undefined (the topic-hub case), incorrectly stripping the bullet from `/topics/payroll-tax-garnishment`. Now only triggers when `stateAb` is truthy AND not in PA/TX/NC/SC.
- **2-click reachability**: original "Browse states" column showed only 12 alphabetically-first states, leaving states 13–50 unreachable from hubs in 2 clicks. Now all 50 state hub links on every topic hub and state hub (2-column CSS layout). State-topic pages keep the 12-state slice to manage weight; their topic-hub link provides the full 50-state reach via the topic hub.
